# カラーミー × Salesforce 顧客データ突合システム

Google Apps Script (GAS) + Claude API (Anthropic) を使った顧客データのクレンジング・名寄せ・突合自動化ツールです。

## 概要

カラーミーショップの顧客データとSalesforceの既存顧客データを突合し、以下を自動化します:

1. **データクレンジング** - 不要なスペース削除、全角/半角統一、性別修正など
2. **顧客突合（名寄せ）** - AI（Claude）による同一人物の推定
3. **アラート機能** - 確証が持てないケースは人間による確認を促す
4. **購買データ照合** - 顧客IDの整合性チェック・書き換え
5. **CSV出力** - Salesforceアップロード用のクリーンなCSV生成

## セットアップ手順

### 1. Google スプレッドシートの作成

1. 新しい Google スプレッドシートを作成
2. メニューから「拡張機能 > Apps Script」を開く

### 2. スクリプトファイルの配置

Apps Script エディタで以下のファイルを作成し、各 `.gs` ファイルの内容をコピー&ペースト:

| ファイル名 | 内容 |
|---|---|
| `01_Config.gs` | 設定・定数定義 |
| `02_ClaudeAPI.gs` | Claude API連携 |
| `03_Cleansing.gs` | データクレンジング |
| `04_Matching.gs` | 顧客突合（名寄せ） |
| `05_Purchase.gs` | 購買データ突合 |
| `06_CsvIO.gs` | CSV入出力 |
| `07_Menu.gs` | メニュー・初期設定 |

### 3. Claude API キーの設定

1. [Anthropic Console](https://console.anthropic.com/) でAPIキーを取得
2. スプレッドシートを再読み込み
3. メニュー「顧客突合ツール > 設定 > APIキーを設定」からキーを入力

### 4. 初期シートの作成

メニュー「顧客突合ツール > 設定 > 初期シートを作成」を実行

## 使い方

### 日次の顧客情報整理フロー

```
1. カラーミーから customer.csv をダウンロード
2. 「CSVインポート > カラーミー顧客CSVをインポート」
3. Salesforceから顧客CSVをエクスポート
4. 「CSVインポート > Salesforce顧客CSVをインポート」
5. 「顧客情報の整理 > データクレンジング実行」
6. 「顧客情報の整理 > 顧客突合（名寄せ）実行」
7. 「アラート」シートで要確認レコードを人間が判定
8. 「顧客情報の整理 > アラート処理結果を反映」
9. 「CSVエクスポート」で処理済みCSVを出力
10. 出力CSVを既存のSalesforceアップロード機能で取り込み
```

### 日次の購買情報整理フロー

```
1. カラーミーから sales_all.csv をダウンロード
2. 「CSVインポート > 購買データCSVをインポート」
3. 「購買情報の整理 > 購買データ突合実行」
4. 「CSVエクスポート > 処理済み購買データCSVを出力」
```

### 一括実行

「全処理を一括実行（顧客）」で手順5〜6を自動実行できます（アラート確認は手動）。

## シート構成

| シート名 | 用途 |
|---|---|
| カラーミー顧客 | インポートした顧客データ |
| SF顧客 | インポートしたSalesforceデータ |
| 突合結果 | AI突合の判定結果 |
| アラート | 要確認レコード（人間判定用） |
| 購買データ | インポートした購買データ |
| 購買突合結果 | 購買ID照合の結果 |
| 削除ログ | 削除した顧客のID記録 |
| 処理ログ | 操作履歴 |

## アラート機能

AIが確証を持てない場合、「アラート」シートに赤背景で表示されます:

- **判定ドロップダウン**: 同一人物 / 別人 / 要調査 / メイン残す / サブ残す / 削除
- **対応メモ**: 自由記述欄

判定入力後「アラート処理結果を反映」で突合結果に反映されます。

## クレンジングルール

| 対象 | 処理内容 |
|---|---|
| 顧客名・フリガナ | スペース削除 |
| 市区町村・番地 | スペース削除 |
| 建物名 | スペース→アンダーバー、番地は市区町村に移動 |
| 性別 | 「未回答」→「選択しない」 |
| 全角英数字 | 半角に統一 |
| 半角カタカナ | 全角に統一 |
| 電話番号 | ハイフン削除 |
| 郵便番号 | ハイフン削除（7桁） |

## 名寄せの精度向上アプローチ

1. **ローカル前処理**: API呼び出し前にルールベースのクレンジングを実行し、表記揺れを最小化
2. **段階的マッチング**: まずカラーミーIDで完全一致を確認し、一致しないもののみAIに判定させる
3. **複合条件判定**: メールアドレス、生年月日、住所、電話番号を総合的に評価
4. **確信度3段階**: HIGH/MEDIUM/LOWで人間の確認優先度を明示
5. **プロンプト最適化**: 日本語の表記揺れパターン（旧字体、カナ混在等）を明示的に指示

## コスト見積もり

- **モデル**: Claude Haiku 4.5（$1.00/$5.00 per 1M tokens）
- **1日10件処理の場合**:
  - クレンジング: 約2回のAPI呼び出し
  - 突合: 約2回のAPI呼び出し
  - 月額推定: 約$1〜3程度（データ量による）

## セキュリティ

- APIキーはスクリプトプロパティに保存（コード内にハードコードしない）
- 顧客データはGoogle スプレッドシート内で処理（外部保存なし）
- Claude APIへの送信は処理に必要な最小限のデータのみ
- 処理ログで全操作を記録・監査可能

## カラーミー顧客CSV想定カラム

```
カラーミー顧客ID, 顧客名, フリガナ, メールアドレス, 電話番号,
生年月日, 性別, 郵便番号, 都道府県, 市区町村, 番地, 建物名,
郵便番号(郵送先), 都道府県(郵送先), 市区町村(郵送先),
番地(郵送先), 建物名(郵送先), ユーザー登録有無
```

## SF顧客CSV想定カラム

```
SF_ID, カラーミー顧客ID, 顧客名, フリガナ, メールアドレス,
電話番号, 生年月日, 性別, 郵便番号, 都道府県, 市区町村,
番地, 建物名, サブフラグ, 購買回数
```

## 注意事項

- CSVのカラム名が `01_Config.gs` の定義と一致している必要があります
- 実際のCSVカラム名が異なる場合は `01_Config.gs` の `COLORME_COLUMNS` / `SF_COLUMNS` を修正してください
- GASの実行時間制限（6分）があるため、大量データの場合はバッチサイズを調整してください
